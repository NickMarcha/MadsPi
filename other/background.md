Project in Informatics: Metrics of Attention Data Streaming and Visualization Pipeline Background Think for a moment about your favorite film. What qualities make this your favorite film? Is it the characters, the plot, the ‘mood’ of the film, or something else? The storytelling devices in your favorite film are also used to tell stories about data–through these stories, the storyteller hopes to help you, the audience, understand or empathize with a topic, just as cinematic films aim to do. Visual data stories are produced in news outlets like the New York Times, or in digital publications such as The Pudding – an example of such a story is shown in the screenshot to the left, with the provocative title, “who killed the world?” Visual data stories like this feel, anecdotally, fun and engaging to explore, but to what extent do they actually make us feel something, or really help us understand the data? The goal of this project is to develop an open-source pipeline to collect and visualize quantitative behavioral data to enable visualization researchers to understand how a reader responds cognitively and emotionally to visual data stories. Assignment For this project, you together with your team will develop an open-source pipeline for collecting data on eyetracking, heart rate, and electrodermal activity (i.e., the small electrical variations detected on our skin when we sweat) when a reader is viewing and interacting with a visual data story. The devices that you will be collecting data from are the Emotibit and the Tobii Pro Spark. Key to a working, integrated pipeline is aligning the clocks of both of these data streams, which you can readily achieve using the Lab Streaming Layer (LSL) system. The end result of this project should be a graphical tool that combines and captures the data streams of the Emotibit and Tobii Pro Spark devices during an experimental session. The tool will ideally be developed for a Linux or Mac OS, although the graphical interface library used should be portable for different operating systems. Design requirements for the tool include: ● Allow the user to select, order, and arrange visual stimuli of interest, with adjustable onscreen time lengths for each stimulus. Visual stimuli for testing will be provided to you and your team ● Launch a eyetracking calibration session that the user may accept the results for, or redo (via a button click) ● Enable the user to start and end the experiment using only the mouse

● Both the calibration and the experimental modes of the application should toggle automatically to fullscreen mode ● Place event markers in the data stream for the beginning of the experiment (i.e., the display of the first of the visual stimuli), each change of stimulus, and the end of the experiment ● Provide a visualization view after an experiment has been run that shows a summary heatmap overlay of eye movements over each stimulus image. Additional visuals include a time overlay of eye movements over each stimulus, with line charts showing the heart rate and electrodermal activity values that correspond with the eye movements. Event markers from the experiment should be visually indicated on the line charts. ● The dataset from the experiment should be exportable as a JSON or CSV file Context This project will be carried out in the context of the Visualization Group at the Department of Informatics, University of Bergen.
